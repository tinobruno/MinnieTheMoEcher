# Changelog

All notable changes to **MinnieTheMoECher** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [v2.07] - 2026-09-04

### Added
- **Qwen 3.8 27B INT4 Support**: Full bare-metal inference support for Qwen 3.8 27B with DeltaNet linear attention and packed INT4 matrix kernels.
- **Multi-Token Prediction (MTP) Speculative Decoding Engine**: Native target-model self-drafting utilizing embedded MTP weights in `attention_dense_layers_q4.bin`, reaching **97.94 tok/s** on RTX PRO 6000 Blackwell (+78% faster than autoregressive baseline, +133% faster than 2B neural drafter).
- **Compact 40,000-Token Draft Vocabulary**: Generated BPE merge vocabulary (`draft_vocab_ids.bin`, 160 KB) and BF16 projection head (`draft_lm_head_int8_bf16.bin`, 390.6 MB), reducing draft memory bandwidth by 6.5x and draft latency to **1.18 ms**.
- **Batched Shared-Memory DeltaNet Recurrence**: Fused `deltanet_ssm_batch_kernel` holding the $128 \times 132$ head state in 32 KB on-chip shared memory across all $M$ verification steps, eliminating intermediate VRAM roundtrips.
- **Batched Causal 1D Convolution**: Implemented `deltanet_conv_batch_kernel` running causal 1D convolutions across $M$ tokens in a single GPU grid dispatch.
- **Batched Centered Normalization**: Implemented `rms_norm_one_centered_cuda_batched` and contiguous `vector_add_bf16_cuda` for single-kernel batched residual addition and RMSNorm.
- **Prompt-Lookup Speculative Decoding (PLD)**: Integrated zero-overhead n-gram pattern matching from recent prompt and generation history for rapid candidate drafting on repetitive syntax and code patterns.
- **Automated Hugging Face Deployment**: Integrated `tools/upload_to_hf.py` and updated `download_model.ps1` to download MTP draft assets directly from [`TinoBruno/moecher-qwen-3.8-27b-q4`](https://huggingface.co/TinoBruno/moecher-qwen-3.8-27b-q4).

### Fixed
- **Stale Post-Norm Hidden State Feedback**: Fixed bug where post-norm hidden states from batched verification (`forward_token_batch_qwen`) were not written to `buf_hidden2_`, which caused MTP self-drafting to branch from stale positions. Acceptance rate surged from 2.6% to **62.0% – 73.6%**.
- **Cross-Architecture Runtime Safety**: Fixed crash (cublasGemmEx error 14) on DeepSeek V4 Flash on simple prompts (`2+2?`) caused by unconditional dispatch into Qwen batched verification; strictly isolated speculative execution behind `cfg_.architecture == ModelArch::QWEN`.
- **Zero-Copy SSM State Routing**: Eliminated 360 redundant D2D memory copies (283 MB) per forward pass by routing token states directly into layer state slots.
- **Adaptive Draft Depth**: Tuned candidate depth to $K = (\text{draft\_streak} \ge 1) ? 2 : 1$ to avoid accuracy drift at $K \ge 3$.

### Removed
- Removed dependency on heavy 2B external neural drafter (saving 1.7 GB VRAM and cutting draft latency by 85%).

## [v2.05] - 2026-08-28

### Added
- **Full-Context Compressed KV Cache**: Fixed 32-entry capacity capping bug in compressor cache, scaling storage across the full 32K token sequence context (`max_seq_len / ratio`), eliminating reasoning context amnesia.
- **$O(V)$ Zero-Sorting Min-P Sampler**: Streamlined vocabulary sampling with an efficient single-pass Min-P algorithm.
- **Thinking & Deliberation Pipeline**: Implemented graceful `<think>` to `</think>` state transitions and handled early EOS gracefully during deliberation.
- **Multi-Turn Chat Formatting**: Added `<｜end▁of▁sentence｜>` delimiters between multi-turn assistant messages.

### Fixed
- **Attention Softmax Scale Correction**: Removed double-scaling bug on attention dot products, aligning attention scaling strictly with $1 / \sqrt{d_{\text{head}}}$.
- **RoPE YaRN Unified Interpolation**: Refactored pair-coordinate RoPE YaRN ramp computation in `activations.cu` with unit magnitude scaling ($mscale = 1.0$), eliminating $(1.277)^2$ over-scaling.

## [v2.03] - 2026-08-20

### Added
- **54 tok/s Milestone**: Boosted generation throughput from $35.2\text{ tok/s}$ baseline to **$53.98\text{ tok/s}$** on NVIDIA RTX PRO 6000 (Blackwell 96GB).
- **Asynchronous Multi-Stream Concurrency**: Non-blocking concurrency between Q and KV projections, and between Routed and Shared experts.
- **Vectorized 128-Bit Hyper-Connection (HC) Kernels**: 128-bit memory operations (`uint4` / `float4`) for hyper-connection pre/post kernels.
- **Fused SwiGLU MoE Execution**: Fused `w1` (gate) and `w3` (up) GEMV into a single CUDA kernel.
- **GPU-Accelerated Top-6 Routing**: Replaced CPU `std::partial_sort` with a GPU block reduction kernel.
- **100% VRAM Resident Experts**: Enabled all 11,008 MoE experts ($72.56\text{ GiB}$) to reside fully in 96GB VRAM in calibrated `IQ2_XXS` + `Q2_K`.
