Moecher v2.09 14.5 tok/s Decode (1.9x Faster)

3-Tier Hierarchy (VRAM Hot + Host DDR5 L2)

Moecher optimizes for generation throughput and interactive responsiveness by caching 3,840 hot experts in hardware NVFP4 (sm_120a mma.sync) in VRAM (67.2 GB) and 4,070 cold experts in pinned host DDR5 RAM (37.7 GB). Because DDR5 DMA transfers over PCIe at ~55 GB/s (vs NVMe's ~7-14 GB/s), cold expert transfers are completely hidden, eliminating random SSD paging stalls. With Native Batched Chunk Prefill (Chunk Size: 512), Moecher achieves 44.26 tok/s prefill (a 4.0x speedup over sequential) and delivers ultra-fast sub-second Time-To-First-Token (619ms on chat, 975ms on code).

  • ✓ 7,910 total cached experts cover >98.7% of token activations
  • ✓ 14.2 GB free VRAM headroom for long 64K KV cache expansion
  • ✓ Zero SSD latency penalty during autoregressive decode
DwarfStar (antirez/ds4) 161.35 tok/s Prefill (Batched GEMM)

Batched Chunk GEMM + NVMe SSD Streaming

DwarfStar excels in prefill by using Batched Chunk GEMM (4,096 tokens/chunk), allowing large prompts to saturate tensor cores concurrently across all routed layers. However, during autoregressive decode (batch size = 1), DwarfStar's single-tier VRAM cache (78.5 GB) requires paging missing cold experts on demand from the NVMe SSD over PCIe for each emitted token, bottle-necking decode throughput to 7.65 tok/s.

  • ✓ High-speed chunked prefill (161 tok/s) on large prompt documents
  • ✓ Efficient low host RAM footprint (only 4.8 GB system memory)
  • ✗ NVMe random read latency (~50-150µs) bottle-necks decode to 7.65 tok/s
